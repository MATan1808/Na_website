# Hệ Sinh Thái 2 Website Bán Hàng (E-Commerce Multi-Store)

Dự án phát triển song song 2 nền tảng bán hàng trực tuyến tối ưu theo từng nhóm ngành hàng:

## 1. Web 1: Cửa Hàng Quà Tặng - Móc Khóa & Gấu Bông 🧸
* **Mục tiêu**: Bán các sản phẩm quà tặng, phụ kiện, móc khóa, gấu bông, blind box.
* **Tính năng đặc thù**:
  - Dịch vụ đóng gói hộp quà cao cấp + thiệp viết tay theo yêu cầu.
  - Cá nhân hóa sản phẩm (khắc tên móc khóa, thêu tên lên gấu bông).
  - So sánh kích thước gấu bông trực quan với vật mẫu thực tế.
  - Combo quà tặng theo dịp (Sinh nhật, Valentine, Tốt nghiệp, Kỷ niệm...).

---

## 2. Web 2: Cửa Hàng Thời Trang Quần Áo 👗
* **Mục tiêu**: Bán quần áo, trang phục thời trang xu hướng.
* **Tính năng đặc thù**:
  - Bảng quy đổi Size & công cụ gợi ý Size thông minh theo Chiều cao / Cân nặng.
  - Bộ lọc thời trang chuyên sâu (Bảng màu trực quan, Form dáng, Chất liệu vải).
  - Mua trọn bộ phối đồ (Shop The Look / Mix & Match).
  - Video người mẫu mặc chuyển động thực tế.
  - Chính sách đổi size nhanh chóng.

---

## 3. Hệ Thống Cốt Lõi (Core E-commerce Engine)
* Quản lý đơn hàng, giỏ hàng, thanh toán COD & VietQR động.
* Tích hợp vận chuyển (GHN, GHTK, Viettel Post).
* Quản lý kho hàng & biến thể sản phẩm đa dạng.
* Hệ thống CRM, tích điểm thành viên và mã giảm giá / Flash Sale.
